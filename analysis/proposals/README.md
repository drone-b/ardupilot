# Proposals

Arquivos gerados em modo observador para extração pontual de domínio:

- `GPS.json`
- `IMU.json`
- `Motors.json`

Cada arquivo contém:

- componente identificável
- função observável no código
- nomes reais de parâmetros
- prefixos reais
- módulos-fonte usados como evidência
- dependências explícitas por include, chamada ou exposição de parâmetros
